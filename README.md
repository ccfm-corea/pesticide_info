# 가농인증 허용 농약 조회 및 방제력 작성

가톨릭농민회 과수위원회 · 가농인증 생산자용 웹앱

농촌진흥청 농약안전정보시스템(PSIS)의 농약등록정보에서 **가농인증 생산규정에 맞는 약제만** 걸러 보여주고,
고른 약제로 **2026년 가농인증 과수 방제력**을 만들어 사진(JPG)이나 PDF로 저장합니다.

- 대상 작물: 사과, 배, 복숭아, 자두, 단감 (생산규정상 가농인증 품목 5종)
- 로그인 없음. 주소만 열면 바로 씁니다.
- 작성 중인 내용과 생산자 정보는 쓰는 사람 휴대전화에만 저장됩니다. 서버로 보내지 않습니다.

---

## 파일 구성

```
index.html                        앱 전체 (한 파일, 빌드 과정 없음)
data/apple.json … persimmon.json  작물별 농약 데이터 (Actions가 매일 갱신)
scripts/build_data.py             PSIS OpenAPI 수집기
.github/workflows/update-data.yml 매일 05:00 자동 갱신
```

앱은 `data/*.json`을 먼저 읽고, 파일이 없거나 못 읽으면 내장 **샘플 데이터**로 동작합니다.
샘플로 동작할 때는 화면 위쪽에 빨간 띠로 알려 줍니다.

---

## 배포 절차

1. **저장소 만들기** — 조직 계정에, **공개(Public)** 로 만듭니다.
   조직 계정이어야 담당자가 바뀔 때 넘기기 쉽고, 공개여야 Pages를 무료로 씁니다.
   생산자 개인정보는 서버에 올라가지 않으므로 공개해도 문제가 없습니다.
2. 이 폴더의 파일을 그대로 올립니다. (샘플 데이터 상태로도 바로 돌아갑니다)
3. **Pages 켜기** — `Settings → Pages → Source: Deploy from a branch → main / (root)`
   1~2분 뒤 주소가 나옵니다. 휴대전화로 열어 화면을 먼저 확인하십시오.
4. **인증키 등록** — `Settings → Secrets and variables → Actions → New repository secret`
   - 이름 `PSIS_API_KEY` / 값 발급받은 인증키
   - 키는 코드나 대화에 절대 넣지 마십시오. Secrets에만 둡니다.
5. **Actions 쓰기 권한** — `Settings → Actions → General → Workflow permissions`에서
   **Read and write permissions**를 고릅니다. 이걸 켜야 갱신된 데이터가 저장소에 커밋됩니다.
6. **서비스코드·필드 확정** (아래 참조) 뒤 `Actions → 농약정보 갱신 → Run workflow`로 한 번 돌립니다.
   `data/*.json`이 실제 데이터로 바뀌면 화면 위 빨간 띠가 사라집니다.
7. 주소를 **QR코드**로 만들어 규정집·분회 월례회의 자료에 넣습니다.
   고령 생산자에게 주소를 손으로 치게 하지 않는 편이 좋습니다.

> 저장소에 60일 넘게 아무 변화가 없으면 GitHub이 예약 실행을 멈춥니다.
> 그때는 Actions 탭에서 한 번 손으로 돌리면 다시 살아납니다.

---

## 배포 뒤 한 번만 하는 일 — 서비스코드와 필드 확정

요청 규격은 아래와 같습니다. 요청 변수 이름은 공개된 호출 예시로 확인했습니다.

```
http://psis.rda.go.kr/openApi/service.do
  ?apiKey=…&serviceCode=SVC01&serviceType=AA001
  &displayCount=100&startPoint=1
  &cropName=&pestiBrandName=&diseaseWeedName=&useName=&pestiKorName=&compName=
```

- 페이지 넘김은 `startPoint` **오프셋** 방식입니다(1, 101, 201 …).
- 아직 확인이 필요한 것은 **등록취소 서비스의 코드**와 **응답 필드 이름**입니다.

```bash
export PSIS_API_KEY="발급받은 키"
python3 scripts/build_data.py probe
```

`SVC01`부터 `SVC10`까지 차례로 불러 어느 코드가 응답하는지, 각 응답에 어떤 필드가 들어
있는지, 현재 매핑으로 무엇이 읽히는지 보여 주고 `probe.txt`로도 저장합니다.
`(못 찾음)`으로 나오는 항목만 `scripts/build_data.py` 위쪽 `FIELD` 표의 후보 목록
맨 앞에 정확한 이름을 넣으면 끝입니다.

등록취소 서비스 코드는 `PSIS_SVC_CANCELLED`에 넣습니다(파일에서 고치거나 Actions Variables).
비워 두면 취소된 농약이 목록에 남습니다.

```bash
python3 scripts/build_data.py build     # data/*.json 생성
```

`build`는 **다섯 작물을 모두 만들었을 때만** 파일을 덮어씁니다. 하나라도 0건이면
기존 데이터를 그대로 두고 오류로 끝나므로, 잘못된 매핑이 빈 목록으로 배포되지 않습니다.
잔류기간·인축독성·희석배수·사용적기 가운데 값이 전부 비는 항목이 있으면 따로 알려 줍니다.

> 등록정보 서비스에 안전사용기준(수확 전 일수·사용횟수)과 독성 등급이 들어 있지 않다면,
> 그 값은 다른 서비스에서 받아야 합니다. probe 결과를 보고 판단하십시오.

## 앱이 걸러내는 것 / 걸러내지 못하는 것

생산규정 3-2 「과수 가농인증 방제 규정」 기준입니다.

| 규정 | 앱 처리 |
|---|---|
| PLS를 따른다 | 등록정보 전체를 원자료로 사용 |
| 맹독성·고독성 금지 | 인축독성 Ⅰ·Ⅱ급 제외 (수집 단계와 화면 양쪽) |
| 제초제 금지 | 용도 살균·살충만 수집 |
| 호르몬제(Ethephon, NAA) 금지 | 생장조정제 제외 |
| 잔류기간 ×2 | 방제력에 `라벨 → 가농` 병기 + 마지막 살포일 계산 |
| **발암성 금지** | **자동 판정 안 됨** — 등록정보에 항목이 없습니다 |
| 항생제 금지 | 위원회 결정에 따라 별도 판정하지 않습니다 |

발암성 항목은 앱 화면에 따로 안내하지 않습니다(위원회 결정).
출력물 아래 설명에는 한 줄 남아 있습니다.
잔류농약에서 금지 품목이 한 번만 나와도 인증이 취소되므로,
제출 전 교구 과수위원회 확인 절차를 앱이 대신하지 않습니다.

---

## 잔류기간 ×2 계산 방식

- 잔류기간 = 라벨의 안전사용기준 「수확 ○일 전까지」
- 가농 기준 = 잔류기간 × 2
- 마지막 살포 가능일 = 수확 예정일 − (잔류기간 × 2)
- 수확 예정시기는 달 + 상순·중순·하순으로 받고, 각각 **1일 · 11일 · 21일**을 기준일로 씁니다
  (그 순의 첫날이므로 안전한 쪽으로 계산됩니다)

「잔류기간」의 해석이 위원회에서 달리 정해지면
`index.html`의 `lastSpray()` 함수 한 곳만 고치면 됩니다.

바뀐 내용이 있을 때만 커밋합니다. 저장소 Actions 탭에서 손으로도 실행할 수 있습니다.
화면 위쪽 「자료 기준일」이 갱신 날짜입니다.

## 만들 때 정한 것

- **성분으로 묶어 보여주기** — 사과만 해도 등록 약제가 수천 건입니다. 성분 단위로 묶고
  상세 화면에서 실제 상품을 고르게 했습니다. 상품 이름으로 바로 찾는 검색창도 함께 둡니다.
- **첫 화면은 작물 고르기** — 조건을 걸지 않은 전체 목록은 보여주지 않습니다.
  첫 동작을 하나로 정해 주는 편이 헷갈리지 않습니다.
- **글자 17px, 누르는 곳 48px 이상**, 아이콘 대신 글자, 지운 것은 되돌리기 가능.
- **사진(JPG) 우선** — 실제로는 카톡으로 보내는 일이 많습니다. 파일 이름은
  `2026_방제력_교구_분회_이름_품목.jpg`로 자동 붙습니다.
  PDF는 인쇄 창의 「PDF로 저장」을 씁니다(글꼴이 깨지지 않습니다).
- **출력물은 한 종류** — 원 양식 순서를 지키고 희석배수·사용횟수 칸을 더했습니다.
  A4 가로이며 줄이 많으면 다음 장으로 넘어갑니다.

## 운영 규칙 (앱 밖의 일)

- 방제력 취합 기능은 넣지 않았습니다. 생산자가 파일로 저장해 교구·전국본부로 보냅니다.
- 분회 공동방제력이 원칙입니다. 개별 생산자는 교구연합회(본부)에 분회 방제력으로 등록해야 합니다.
- 규정은 친환경 유기인증 농약을 먼저 쓰고, 그것으로 안 될 때 합성 화학농약을 최소로 쓰도록 합니다.
  이 앱은 합성 화학농약을 찾는 도구이므로, 순서가 뒤바뀌지 않게 안내해 주십시오.
